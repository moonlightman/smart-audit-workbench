# 2026-11-01 需求校正决定（优先于旧方案冲突部分）

本次来自负责人对本地前端的反馈。前端仅用于校正需求，不是正式版或最终目标，演示交互不得作为生产能力或完整需求的验收证明。旧版技术方案、总体计划与Word保留历史；下列范围变更由用户明确提出，后续Dot必须先读本文件再拆任务。旧44周排期不再作为新范围的有效预测，细化新需求后重估。

## 角色、项目与合同

- 工程管理：新建修改本人项目、选择造价对接人、维护归档与报送，收到最终成果。
- 造价审计：按分配接收、初审、线下审核、成果分析与提交；下一级复审由独立人员完成。演示提供林岚初审、周宁复审，正式角色关系待配置。
- 资料查阅：仅能访问授权参考数据库、集团资料和查询功能，不新建修改项目或报送数据。数据库访问不等于获得直连数据库账号，也不等于全项目资料开放。
- 超管：维护发布信息、修改任意业务数据、全部操作权限；正式系统仍须记录变更和原因，不能省略审计历史。

项目是主线，一个项目可含多个合同，一个合同可多次进度款或结算报送。审核状态属于每次报送及其版本，不能用一个项目状态覆盖多合同。顶部始终保留项目切换；工作台统计当前角色授权范围，不只统计顶部单项目。

## 工作台与项目报送

工作台展示跟踪、已完成、待办、已归档项目数量，下方台账第一列项目号、第二列台账名称，展示合同数和跟进操作。已完成与已归档是两个独立口径；待办项目按项目去重，正式版按角色对应待处理动作计算。

项目台账包含本人项目查看、新建修改及概况附件下载。字段：项目名称、项目公司、所属板块（协鑫科技/协鑫集成/协鑫能科）、工程类别（新建/改建/扩建/检维修/技改）、项目负责人、造价对接人、状态（筹建/在建/竣工/停建/已结束）、预算。项目建立独立逻辑文件夹，附件按类别归档。

资料报送仅保留进度款上报、结算上报，不分阶段目录。每次选择合同并上传本次资料，上报后进入指定审计人员待办。审计人员签收或退回；退回必填理由，保留回复意见。撤回、修改重报、删除保留历史和版本，删除采用逻辑删除。

## 平台变更

数据汇集平台暂不建设，替换为仅超管可见的数据库栏。大数据分析平台暂不建设，入口替换为招投标平台，先保留DeepSeek对话。原数据汇集、分析模型与湖仓专项退出当前实施范围，未来是否恢复由负责人新决定，不再自动视为本轮必需项。

## 审计管理主线

审计项目是造价人员主要工作入口。签收后待审核，下载报送资料后进入审核中；AI预审弹出结果。下载动作只是开始工作的信号，不能据此认定已完成实质审核。线下审核后上传成果，AI分析生成审计报告及审定单，正式模板由负责人提供。

成果提交进入下一级复审，复审退回须写理由，初审修改重提；复审完成后反馈工程管理。初审提交可标已审核，但待复审与最终完成必须区分。上传人可撤回、修改、删除自己的提交；最终完成后的操作保留旧版和回退轨迹。手动改状态记录原因，不能用普通初审越过最终复审。超管修正亦保留历史。

## 数据支撑与集团资料

1. 信息价按地区、月份查询，保留口径与来源。
2. 网页询价是轻量浏览工作区，提供惠讯网、我的钢铁网、材价助手、淘宝等入口。站点限制嵌入或登录时使用原站新窗口；不承诺嵌入均可用，不绕过原站限制。未确认站点网址由维护人员配置。
3. AI询价接受Excel材料表或自然语言，DeepSeek以自然语言汇总，价格必须有时点、规格、税费与来源；无结果如实说明。
4. 造价指标来自已完成项目及已复审的审定数据，不把预算当审定额，样本不足不生成虚构指标。
5. 知识问答先由模型分类，集团制度问题检索已发布知识库并引用；其他问题通用回答。分类不确定时先澄清，不能用通用知识冒充集团制度。
6. 集团信息仅资料中心，超管直接维护更新、发布撤回；查阅用户可预览详情、下载、制度问答。维护能力放资料中心内，不独立占导航。

## 本轮原型边界与待确认

原型路径frontend，角色过滤只是交互示例，无后端安全边界。附件使用浏览器IndexedDB，元数据localStorage；换浏览器、清缓存或配额不足会影响资料，不能作正式档案。通知为本地共享状态待办，不是消息服务。AI响应为明确标识的模拟；Excel保存但未解析，正式报告模板未提供，预览先展示摘要，正式PDF预览后续补齐。外部询价与真实价格未验证。
