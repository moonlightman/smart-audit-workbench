# 智慧审计平台项目推进报告

版本 V2.0　日期 2026年10月31日　读者：项目负责人

## 一 你怎样推进这个项目

项目可以按“一位业务负责人加AI开发协作”组织。你负责资料收集整理、需求确认、验收和判断；Dot负责组织任务与跟踪进度，Codex负责开发与检查。本报告告诉你每一阶段要提供什么、看什么、决定什么。它不是已经开发成功的证明。

建设目标保持不变：项目报送平台、数据汇集平台、大数据分析平台、审计管理平台、数据支撑平台、集团信息平台，统一工作台、PC网页、优先使用开源组件，产品里的LLM全部使用DeepSeek。集团资料由你或未来获授权的维护人员人工发布，系统负责查阅下载和受控检索；当前建设计划只有你一位人工参与者。

## 二 目前建议怎样投入

先用两周评估资料与范围，再决定是否开通Pro。先不按额外技术人员已经到位计算。计划暂按你每周6至10小时业务参与估算，时间可分散安排，实际以你确认和前期记录为准。你不用承担写代码或数据库检查，AI需要把技术检查结果转换成你能看懂的演示和问题清单。

每周建议做三件事：集中提供一批资料；看一次功能演示并验收；处理一份简短的需求与费用判断清单。AI应减少碎片式提问，同一轮尽量将需判断的问题合并，不用技术术语代替说明。

## 三 第一批要准备的材料

| 材料 | 你需要做什么 | 供AI验证什么 |
| --- | --- | --- |
| 一个工程项目 | 整理合同、清单、报价、付款或结算资料 | 项目关联、金额、版本和审计路径 |
| 集团资料 | 合同范本、制度、造价信息、汇编各至少一份 | 人工发布、检索、预览和下载 |
| 一份满意的成果样表 | 标出必须固定的表头和结论位置 | 程序稳定生成，AI负责分析内容 |
| 现行审计规则 | 说明谁编制、谁复核、哪些情况退回 | 流程和职责冲突处理 |
| 文件与接口情况 | 告知造价软件及版本，能否导出 | 格式和授权依赖 |

先提供脱敏材料即可，AI不能因历史库为空停止对原始资料的分析。真实合同和个人信息不默认放入代码仓库。缺失金额不当作0，可比性不明要先向你核实，分析异常不直接认定违法或串标。

## 四 什么时候能用到什么

当前估算为44周建设加8周缓冲，起点由你确认，未给定实际开工日期。它替代上一版32周估算，不是完成承诺。第6周和以后每四周，用真实任务耗时调整剩余安排。

| 相对时间 | 你会看到的成果 | 你需要判断什么 |
| --- | --- | --- |
| W1—2 | 项目评估与样本清单 | 是否立项、预算与每周可用时间 |
| W3—6 | 四个真实最小样例 | 样例是否贴合实际；是否开始正式开发 |
| W7—14 | 统一工作台与集团信息平台 | 能否发布、查找、预览、下载和撤回资料 |
| W15—22 | 项目报送与数据整理 | 报送补正是否顺畅；提取金额和来源是否正确 |
| W23—28 | 一个项目核心审计闭环 | 能否形成问题、底稿、校审和固定成果 |
| W29—36 | 数据支撑与六平台常规功能 | 引用、价格口径和审计类型是否完整 |
| W37—40 | 湖仓及约定格式专项 | 对应样本是否真正接通 |
| W41—44 | 整体试运行与恢复演练 | 总体必需项是否通过、是否正式发布 |
| W45—52 | 必要的等待与返工空间 | 根据实际情况重新安排，不默认新增需求 |

你若连续两周不能提供资料或验收，AI应先完成不依赖你的检查，再调整计划。不能用“AI可以一直运行”推断日历工期必然缩短。

## 五 每次验收只需要看这些

AI给你一个演示版本、一组操作步骤和预期结果。你按步骤操作，核对资料、金额、来源与业务流程，再回复通过、需修改或暂缓。示例：上传制度，审核发布，检索打开；撤回后再检索，普通账号不应继续看到正文。系统是否正确，你看实际操作和来源即可，不需要阅读代码。

验收意见应绑定版本，避免“上次看过所以这次也通过”。已经通过的功能修改后要回归。系统自动计算金额，AI解释差异，你确认业务适用性和最终结论。权限与恢复测试由AI提供实际执行记录；没有验证结果的关键问题不得包装成已经安全。

## 六 你怎么看进度

打开仓库README找到STATUS，看当前阶段、已经验收的需求、下一项演示、阻塞和需要你判断的事情。每周报告应注明本周可用成果、未完成项、你的下一项动作和最新工期预测。没有证据的“完成90%”不作为进度依据。

整个项目不是六套互不相通的小系统：它们共用账号、项目和文件，但每个平台菜单和职责清楚。第28周的核心试点只代表一条链路可用；只有六平台必需清单及专项都验收后才能说整体完成。

## 七 费用与目前的判断

Pro订阅、DeepSeek API、服务器与存储、可能的造价SDK及接口费用分别记录。Pro不等于产品DeepSeek调用免费；Dot可用性以账号实际入口为准。具体费用上限待你在评估期确认，AI不自行购买或提高预算。

建议先按评估期推进：选一个试点项目，提供一批集团资料与成果样表，确认每周可投入时间。评估结束后看证据决定继续、调整或暂缓。仓库是持续推进的依据，聊天中的新决定应写回仓库，避免后续AI丢失上下文。
