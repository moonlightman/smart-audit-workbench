# 需求校正前端 V2

使用Vue3、TypeScript、Element Plus与Vite。根据2026-11-01负责人反馈制作，用于业务校正，不是最终版。入口工作台、角色切换、合同报送与初复审、超管资料中心和支撑查询。

## 运行

Node 22环境执行 `npm ci`、`npm run dev -- --host localhost --port 7100`。浏览器访问 http://localhost:7100/workbench 。`npm run build`检查类型及构建，`npm test`检查状态流转。生产部署未授权。

工程管理陈明与初审林岚、复审周宁是合成人员。先在工程管理的资料报送查看BS-001，再切造价审计签收、下载进入审核中、上传成果、提交复审，切周宁复审通过，切回工程管理看反馈。新项目先增加合同再上报。资料中心维护仅超管可见。AI与信息价均为明确标注的模拟数据。

原型初始来源为Kimi本地演示的Vue/Vite依赖配置；新原型使用独立入口和状态模型，原Kimi页面不作为最终规范。当前原型入口不依赖旧路由。附件存在IndexedDB，元数据存在localStorage的audit-requirements-v2，与旧演示数据隔离；不放真实资料。外部网站可能禁止嵌入，提供原站新窗口。未确认站点地址不猜测。

正式实现缺口详见../docs/REQUIREMENTS_V2.md。浏览器角色切换不构成权限隔离，模拟AI不构成模型接入，上传Excel不代表解析成功，生成字段草稿不代表正式审计报告。
