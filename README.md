## 当前事实

本仓库初始化交付规划与协作文件，产品开发尚未开始。只有一位人工参与者；44周建设加8周缓冲是待校准估算，T0未确认。旧版32周估算不再适用。GitHub上传不自动启用Dot，也不代表已购买Pro或连接生产环境。

负责人先阅读推进报告，再决定启动P0。Dot首次启动先读AGENTS与执行计划，准备P0评估包。所有后续决策与验收写入仓库。正式产品发布与购买服务另按明确授权执行。

## 目录约定

docs保存当前规范，tasks保存任务，evidence保存合成/脱敏检查证据，deliverables保存本轮Word。真实业务原件与密钥放受控空间，仓库不默认收集。尚无应用源码、可运行产品或生产部署。当前材料未授予开源许可证；复用组件应各自保留原许可证。
